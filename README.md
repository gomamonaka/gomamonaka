# MS — 業務自動化・社内ツール開発（ITヘルプデスク / フルスタック）

中小企業・個人事業主向けに、**手作業の繰り返し業務をツール化**する業務委託エンジニアです。
本業はITヘルプデスク。「現場の困りごとを聞き取る → 動くものを作る → 使い方まで説明して納品する」を一貫して対応します。

> 雇用形態での副業は行っておりません。 **業務委託（納品型）** のみ対応しています。

## こんなお困りごとに対応します

- Excel / CSVの整形・集計を毎回手作業でやっている
- 問い合わせの分類・返信文の下書きに時間がかかっている
- Webシステムへの転記・登録作業が単調でミスも多い
- AIで作ったツールが動かなくなったが、直せる人が社内にいない
- 社内向けの小さなツールやChrome拡張を作りたい

## 進め方

1. **無料ヒアリング（30分）** — 困りごとと現在の手順を聞きます
2. **固定見積もり** — 納品物・納期・価格を先に確定します
3. **開発** — 進捗は随時共有します
4. **納品・説明** — ソースコード、マニュアル、動作確認ログをお渡しします

## 制作物・デモ

- **[webautolab-portfolio](https://github.com/gomamonaka/webautolab-portfolio)** — 業務自動化デモ集
  - 問い合わせをAI分類してExcel化（カテゴリ・要約・緊急度・返信案まで自動作成）
  - バラバラ表記のCSVを整形してグラフ付きExcelレポートを自動生成
  - Chrome拡張で一覧のCSV保存・フォーム自動入力を1クリック化
  - Webスクレイピング（レート制限・リトライ・利用規約遵守の設計）
  - 動かなくなったツールの復旧ケーススタディ（診断レポート付き）
- **[Yorisoi-ClickOnce](https://github.com/gomamonaka/Yorisoi-ClickOnce)** — Chrome上のリンクからClickOnceアプリを起動する拡張機能＋Native Host＋インストーラー一式
  - C# / .NET 8、設計書・脅威モデル・セキュリティ方針・単体テスト完備
  - セッション情報を扱うため、ログに認証情報を残さない設計を徹底
- **PetaPin（ぺたピン）** — Windows向けスクリーンショット・画面ピン留め・注釈・ローカルOCRアプリ
  - 単一EXE／ZIP／インストーラーの3形式で配布できる形まで実装
- **ChatHub** — 複数のビジネスチャットを1つのWindowsアプリに集約するクライアント
  - アカウントごとのセッション分離、未読バッジ、Windows通知連携、省メモリ設計（WebView2）
- **ExtIMEDicBuilder** — 複数行の定型文をMicrosoft IMEの変換候補に登録するWPFアプリ
  - 生成結果が仕様とバイト単位で一致することを単体テストで検証
- **ClipBridge** — 2台のWindows PC間で暗号化してクリップボードを共有する常駐アプリ

### 概要のみ紹介（コード非公開）

- **エスカレーション支援エージェント** — チャットの通知を起点に、対応が必要な会話を検出して案件化する仕組み。読み取り専用で、送信・更新は行わない安全設計
